# Newsroom public training demo

Public entry: `/newsroom/demo/`. No login, API credentials or protected data are included.

Nine replay scenes teach assignment, outline/media submission, Bengali drafting from English/Bengali/Romanised Bengali instructions, editorial correction, approval, arrangement, format adaptation and exports. Playback supports pause, restart, speed and manual chapters. Sample uploads and Nexus answers are deterministic demonstrations, not live model calls. Arrange buttons and drag actions change session-only preview state; the fixed downloadable examples do not change.

Seven fictional reporters are shown across two desks. Three Uttarpara Municipality service/initiative summaries use official municipal pages. The remaining stories use UNICEF, ISRO and ICC. Every story preserves its actual historical date or states that its official service source is undated. No fabricated interview, invented achievement or current service-performance figure is presented as fact. Artwork is labelled as illustration. This is not an official municipal publication.

`data.json` contains source links and checked dates. `reports/` includes a reader and three PDFs: newspaper (3 pages), press reports (6 pages) and social cards (6 pages). The local Bengali font is included under the accompanying SIL OFL license. Print/PDF output was rendered and visually checked.

Built as static assets for the existing GitHub Pages site. Keep the private production workspace's login and permissions unchanged. Do not place user credentials or model keys in this demo.
