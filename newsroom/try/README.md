# Public team practice workspace

A deliberately isolated browser-local simulation for visitors to yogabrata.com/newsroom/try/. It uses public fictional demo accounts only. It never sends login values, stories, photos, or other data to the private portal or a live model. All state is stored in localStorage on this browser; different devices do not share submissions. Closing/reopening preserves practice state; Reset Practice restores it.

The public moderator is testuser / p@ssword. Three reporters are testreporter1, testreporter2 and testreporter3, with username + @44# passwords. Those account identities also exist separately in the real private portal's Demo Reporting Team. The practice workspace is not an authentication boundary and must never contain real private content or API keys.

Practice flow: sign in as reporter, create/edit a story, attach a sample image with caption/credit/permission, use a clearly labelled predetermined Demo Draft response, submit. Sign out; sign in as editor; request changes or approve; add approved stories to an edition, reorder/page them, preview and Print / Save PDF. The editor can remove/re-add a registered dummy reporter to demonstrate membership without changing credentials. Subhajyoti's Team is managed in the real portal; the public practice workspace has only the demo team.
